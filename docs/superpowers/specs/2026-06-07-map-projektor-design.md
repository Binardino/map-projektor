# Map Projektor Universal Converter — Design Spec

Date: 2026-06-07

## Goal

A small educational web app displaying a world map in ~12 different cartographic projections, with animated transitions between each projection. Built as a Python/FastAPI learning project.

---

## Stack

| Layer | Technology | Role |
|---|---|---|
| Server | FastAPI + uvicorn | Serves HTML, GeoJSON, static files |
| Templating | Jinja2 | Renders `index.html` |
| Cartography | D3.js + `d3-geo-projection` | Projections, SVG rendering |
| Morph animation | flubber.js | Smooth SVG shape interpolation |
| Data pipeline | Python (`requests`, `shapely`) | Fetch + simplify GeoJSON (one-shot script) |

## FastAPI Server (`app/main.py`)

Three routes only:

```python
GET /                    # serves templates/index.html
GET /data/world.geojson  # serves app/data/world.geojson
mount /static            # serves static/ directory (CSS, JS)
```

Run with: `uvicorn app.main:app --reload`

---

## Data Pipeline (`scripts/fetch_geodata.py`)

One-shot script, run once to generate `app/data/world.geojson`.

**Steps:**
1. Fetch Natural Earth 110m countries GeoJSON from:
   `https://raw.githubusercontent.com/nvkelso/natural-earth-vector/master/geojson/ne_110m_admin_0_countries.geojson`
2. Simplify geometries using Douglas-Peucker algorithm via `shapely` (tolerance=0.5)
3. Truncate all coordinates to 4 decimal places
4. Retain only necessary properties: `NAME`, `CONTINENT`
5. Save to `app/data/world.geojson`

The generated GeoJSON file is gitignored — only the script is versioned.

## Projection Data Structure (`static/js/map.js`)

`PROJECTIONS` array — adding a projection means adding one object, nothing else changes.

```js
const PROJECTIONS = [
  {
    id: "mercator",
    name: "Mercator",
    family: "Cylindrical",
    year: 1569,
    description: "Preserves angles (conformal). Severely distorts area near the poles. Standard for maritime navigation for centuries.",
    d3fn: () => d3.geoMercator(),
  },
  // ...
];
```

**12 starting projections (one per family):**

| Family | Projections |
|---|---|
| Cylindrical | Mercator, Equirectangular |
| Pseudocylindrical | Robinson, Mollweide, Natural Earth, Sinusoidal |
| Azimuthal | Orthographic, Azimuthal Equal Area |
| Conic | Albers |
| Pseudoazimuthal | Winkel Tripel, Aitoff, Hammer |

The sidebar is generated dynamically from this array — no HTML to write per projection.

> **Note:** Winkel Tripel, Aitoff, and Hammer require `d3-geo-projection` (not included in D3 core).

## Transition Animation

Three-step sequence triggered on projection button click:

```
[Projection A]
    ↓  500ms — morph to orthographic globe (flubber.js path tween)
[Globe]
    ↓  400ms — slight globe rotation (+30° longitude)
[Globe]
    ↓  500ms — morph to Projection B (flubber.js path tween)
[Projection B]
```

Sidebar buttons are disabled during the transition to prevent cascading clicks.

## Visual Theme — Vintage Colorful

All colors defined as CSS variables in `static/css/style.css`. Changing the theme = editing this block only.

```css
:root {
  /* Backgrounds */
  --bg-app:        #f2ead8;   /* light parchment */
  --bg-sidebar:    #e8dfc8;   /* darker parchment */
  --bg-ocean:      #c8d8e0;   /* soft blue ocean */

  /* Continents */
  --color-africa:      #e8c84a;
  --color-europe:      #7cb87a;
  --color-asia:        #d4a84a;
  --color-americas:    #88c47a;
  --color-oceania:     #c4a050;
  --color-antarctica:  #ddd3be;

  /* UI */
  --text-primary:  #3d2b0a;
  --text-muted:    #8b6f47;
  --accent:        #8b6f47;
  --border:        #c8b890;
  --active-bg:     #d8ccb0;
}
```

Countries are colored by continent using the `CONTINENT` property from the GeoJSON.

## Implementation Order

1. Minimal FastAPI setup + empty HTML → running server
2. Write `fetch_geodata.py` → generate `world.geojson`
3. Render world map with D3 using Mercator as default
4. Dynamic sidebar generated from `PROJECTIONS[]`
5. Projection switching without animation
6. Morphing animation + intermediate globe state (flubber)
7. Apply vintage colorful theme + CSS variables

---

## Extensibility

- **Add a projection:** add one object to `PROJECTIONS[]`, nothing else changes
- **Change the theme:** edit CSS variables in `:root`
- **Add more projections later:** switch to `d3-geo-projection` (70+ projections) — same object structure, just different `d3fn`
